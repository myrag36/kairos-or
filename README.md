# Kairos Or

Bureau privé de trading sur l'or (XAU/USD) : graphique et actualités en direct, plans de trade, niveaux clés, calendrier, calcul de taille et journal.

- `index.html` : le site (une seule page, sans dépendance à installer).
- `data/analysis.json` : l'analyse du jour, mise à jour par Claude.

Analyse éducative, pas un conseil en investissement.
